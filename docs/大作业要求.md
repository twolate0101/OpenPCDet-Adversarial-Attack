# 《软件质量保障》大作业提纲
大作业暂定共10个方向，每个方向3个小组，每个小组5人，小组在第1-2周进行方向选择。主要内容包括如下：
* 1、每个小组领域调研后，确定所选择开源项目，在上机课中进行PPT选题汇报（包括领域调研论文+工具、选择该开源项目的理由、以及可能的改进思路）。
    注:论文检索可参考Google Scholar、IEEE Xplore、ACM Digital Library等学术数据库，工具选择可参考GitHub、GitLab等开源平台。
* 2、围绕所选择的开源项目进行搭建、分析以及改进，完成相关实验，并进行结果汇总，在上机课进行PPT完成情况汇报。
* 3、完成项目部署（上传github），撰写报告一篇（参考软件学报论文格式）。
* 评分规则：每个题目3个小组，最终成绩分为高-中-低三挡，满分为30分，高档21-30分（解析工具功能+针对现有工具有改进），中档11-20分（解析工具功能+复现工具对应论文中的实验结果），低档0-10分（无法完成工具解析以及实验结果复现），组长（1名）+5分，核心成员（不超过30分）。

# 本组选题
三维点云感知算法的对抗攻击与安全性验证
（可参考 PointNet、PointNet++、OpenPCDet 等开源框架）
围绕点云目标检测或分类模型，复现典型点云对抗扰动方法（如点坐标微扰、点插入或点删除），分析模型在三维空间扰动下的稳定性与检测精度变化，完成系统化实验评估。在此基础上，鼓励探索具有物理合理性的扰动构造方法，或设计轻量级鲁棒增强策略，并对其有效性进行对比验证。
